{{tool}} is the command-line tool of AgentVision, which gives AI agents fast access to webcams. This release
offers the standard options, self-validation, and this built-in help; the webcam commands are planned and are
not available yet.

Every operation is an option. The only command is `{{tool}} help`, which must be the first argument and takes
topic names, such as `{{tool}} help command-line`.
